# v1.1.1 — 修复 Wayland 下 dock/任务栏残留“打不开的窗口”

Linux 小版本修复：关闭窗口后不再使用“隐藏窗口”，改为**最小化到任务栏/托盘**，从而在
GNOME Wayland 下不会留下无法打开的 dock 图标。

## 🐛 修复

- **Wayland 下关闭窗口后 dock 残留失效项**：Wayland 不支持隐藏窗口（winit 的
  `set_visible` 为空实现），旧版走 Slint 的 `hide()` 会直接销毁窗口表面，桌面 Shell 却
  仍保留一个打不开的图标。现在 Linux 上关闭窗口改为 `set_minimized(true)`，任务栏/dock
  里的窗口可正常点击唤回；Windows 仍保持原有的托盘隐藏行为。
- **从托盘/任务栏唤回窗口**：新增统一的窗口唤醒逻辑；Wayland 客户端无法自行取消最小化，
  因此通过“销毁并重建表面”的方式显示窗口，托盘菜单“显示主窗口”和再次启动程序都能正常
  唤出窗口。
- **关闭按钮不再触发 Slint 的 `HideWindow`**：避免同一路径上再次销毁 Wayland 表面。

## 📦 其它

- 版本 1.1.1，Linux 一键安装脚本默认安装该版本；升级可直接重跑安装命令。
- 无协议、配置格式或 CLI 参数变化，可直接覆盖升级。

## ⚠️ 已知限制（不变）

- Linux 版尚未经过长期真实账号保活实测；请留意在线状态。
- GNOME 需要 AppIndicator 扩展才显示托盘；没有托盘时窗口最小化到任务栏，属于正常状态。
- 发布包按构建机 glibc 链接；较旧发行版请从源码构建。
- Linux 凭据为 0600 权限明文 JSON；静态 IPv4 依赖 NetworkManager；改路由需要 root。
