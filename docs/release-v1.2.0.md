# v1.2.0 — 自绘标题栏、关闭后静默运行、托盘最小化

Linux 桌面体验更新。

## ✨ 新特性

- **自绘标题栏**：窗口不再使用系统原生标题栏（`no-frame` + Client-Side Decoration），
  标题栏由 Slint 绘制，跟随浅色/暗色主题。拖动标题栏移动窗口，右侧提供
  `—` 最小化与 `×` 关闭按钮；拖动通过 winit 的 `drag_window()` 交给合成器处理，
  Wayland / X11 均可用。
- **关闭即静默运行**：默认关闭按钮不再退出程序，而是在后台继续认证与保活：
  - 有系统托盘（KDE、XFCE、装了 AppIndicator 扩展的 GNOME 等）→ **最小化到托盘**，
    托盘菜单可唤回窗口或退出；
  - 没有托盘 → **最小化到任务栏**，点击任务栏图标或再次启动程序即可唤回；
  - 取消勾选“关闭到托盘 / 关闭后静默运行”后，关闭按钮才真正退出。
- **最小化按钮与托盘一致**：有托盘时标题栏的 `—` 也最小化到托盘；无托盘时最小化到任务栏。
- 从托盘菜单“显示主窗口”或再次启动程序唤回窗口时，会重建 Wayland 窗口表面
  （Wayland 客户端无法自行取消最小化）。

## 📦 其它

- 版本 1.2.0，Linux 一键安装脚本默认安装该版本；可直接重跑安装命令覆盖升级。
- 无协议、配置格式或命令行参数变化。

## ⚠️ 已知限制

- Linux 版尚未经过长期真实账号保活实测；请留意在线状态。
- GNOME 需要 AppIndicator 扩展才显示托盘图标；没有托盘时窗口最小化到任务栏属正常状态。
- 发布包按构建机 glibc 链接；较旧发行版请从源码构建。
- Linux 凭据为 0600 权限明文 JSON；静态 IPv4 依赖 NetworkManager；改路由需要 root。
