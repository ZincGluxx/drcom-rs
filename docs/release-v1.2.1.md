# DrCom Rust v1.2.1

修复从托盘重新打开窗口时上半部分渲染不出来的问题，并补回按需建窗重构漏掉的回调接线。
本版与 Linux 分支（v1.2.0）共用 1.2.x 版本序列；此前 Windows 线停在 v1.0.4。

## 修复

- **窗口重新打开时整窗重绘。** Slint 的 Windows 软件渲染器按脏矩形提交
  （`present_with_damage`），只把本帧重绘过的区域贴到窗口；窗口隐藏期间系统会用背景刷
  把客户区擦成白色，而 winit 在 Windows 上不上报 `Occluded`，渲染器的局部重绘缓存不会
  被重置。结果重新显示后只画出"显示之后发生变化"的那一小块（例如每秒刷新的在线时长），
  其余部分保持空白。现在关闭到托盘、登录后自动进入托盘都会**销毁窗口组件**，下次打开重建
  窗口，首帧必然是整窗重绘。
- **补回窗口回调接线。** 按需建窗重构后 `bind()` 只回填了状态、没有注册回调，从托盘重新
  打开的窗口上，连接/断开/刷新/检测网络/复制结果/保存结果/网络设置等按钮全部无响应，
  网页状态探测也不会启动。现在每次建窗都会重新接线并回填状态。

## 内存

- 窗口在第一次需要时才创建，关闭到托盘即释放，托盘常驻不再持有渲染目标：
  隐藏后私有提交 **5.71 MiB → 4.18 MiB**（Windows x64 实测）。

## 兼容性

- 窗口固定尺寸、浅色/暗色主题跟随与整体布局未变；账号设置、开机启动设置全部保留。
- 开机启动改为以 `--tray` 静默启动（启动后直接留在托盘，不弹窗口）；旧版本写入的、
  不带该参数的启动项仍被识别为"已开启"，不会把复选框悄悄关掉。

## 验证

- `cargo test --offline`：**109 项测试全部通过**（86 项库测试 + 23 项 GUI 测试）。
- `cargo clippy --all-targets` 与 `cargo fmt --check` 均无告警。
- 新增 `examples/open_probe.rs` 复现探针：`OPEN_MODE=reshow` 稳定复现原问题，
  `release-reshow` 验证修复。
- 发布版二进制在隔离配置下实测：开窗 → 关闭到托盘 → 再次启动（等价托盘"显示主窗口"）、
  `--tray` 启动后开窗、标题栏最小化/还原，均整窗正常渲染。

## 安装

下载 `DrComRust_v1.2.1_Setup.exe` 运行即可，会覆盖安装到原有目录并保留配置与开机
启动设置。校验值见 `DrComRust_v1.2.1_SHA256.txt`。系统要求 Windows 10 / 11 x64；
不安装驱动，日常运行不需要管理员权限（安装与更新需要）。安装器会先结束正在运行的旧客户端。
