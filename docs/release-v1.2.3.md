# v1.2.3 — 纯托盘运行、修复 dock 幽灵窗口、开机自动登录更可靠

## 🐛 修复

- **GNOME 下 dock 里“关不掉、打不开”的窗口**：窗口之前没有设置 Wayland app_id /
  X11 WM_CLASS，GNOME Shell 无法把窗口和应用入口 `drcom-campus.desktop` 关联起来，
  隐藏到托盘后会在 dock 里留下无法打开的幽灵项，托盘菜单也可能失效。现在启动时设置
  `slint::set_xdg_app_id("drcom-campus")`，并在桌面入口写入
  `StartupWMClass=drcom-campus`，Shell 能正确识别窗口。
- **纯托盘方案**：有托盘时，标题栏关闭 / 最小化都隐藏到托盘，dock / 任务栏不再保留
  窗口项，只留托盘图标（菜单可显示窗口或退出）。没有托盘时才退化为最小化到任务栏。
- **开机自动登录不再被网页预检跳过**：启动时的只读网页状态检查此前在检测到“已有认证”
  时会取消自动登录，导致开机后要手动连接。现在该检查只更新状态文字，不影响自动登录；
  等待可用网卡的窗口也从 90 秒放宽到 5 分钟，覆盖开机 DHCP / Wi-Fi 关联较慢的情况。
- **开机第一次登录被拒后自动重试**：重启后服务器可能仍记录着上次的会话，首次登录返回
  错误码 1 / 7 / 11（地址或设备状态不匹配）。现在会等待 5 秒让服务器释放旧会话，
  然后重试一次；真实冲突仍然只尝试一次便停下来并给出原因。
