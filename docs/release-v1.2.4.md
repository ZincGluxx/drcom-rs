# v1.2.4 — 托盘程序：关闭即后台静默运行，窗口一定能重新打开

本次修复针对 Linux 桌面（尤其是 GNOME + Wayland）上“托盘点不开、dock 残留窗口”的问题。

## 🐛 修复

- **从托盘 / 再次启动唤回窗口时窗口是空白或根本没出现**：窗口重新显示时不会触发首次重绘，
  Wayland 下表现为“窗口没出来”或“只画了一部分”。现在唤回时会显式请求重绘，实测
  唤回后立即创建缓冲区并 attach/commit，窗口正常显示。
- **dock 里“关不掉、打不开”的幽灵窗口**：窗口缺少 Wayland app_id / X11 WM_CLASS，
  GNOME 无法把它和应用入口 `drcom-campus.desktop` 关联起来。现在启动时设置
  `set_xdg_app_id("drcom-campus")`，桌面入口写入 `StartupWMClass=drcom-campus`。
- **纯托盘方案**：有托盘时，关闭 / 最小化都隐藏到托盘，dock 与任务栏不保留窗口项，
  只留托盘图标（菜单可显示窗口或退出）；没有托盘时才退化为最小化到任务栏。
- **开机自动登录更可靠**：
  - 启动时的只读网页状态检查不再取消自动登录（之前检测到“已有认证”会跳过登录，
    导致开机后要手动点连接）；
  - 等待可用网卡的时间从 90 秒放宽到 5 分钟，覆盖开机 DHCP / Wi-Fi 关联较慢的情况；
  - 首次登录被拒（错误码 1 / 7 / 11，通常是重启后服务器仍记录着上一次会话）时，
    等待 5 秒让服务器释放旧会话并自动重试一次；真实冲突仍只尝试一次便停止。

- 托盘提示文字在唤回窗口后会更新为“窗口已打开”。
