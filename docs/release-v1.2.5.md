# v1.2.5 — 修复自绘标题栏错位

## 🐛 修复

- **标题栏内容整体居中错位**：标题栏那一行用了 `alignment: center`，它把整行内容（图标、
  标题、最小化/关闭按钮）都挤到了中间。改为 `cross-axis-alignment: center` 后，图标与
  标题靠左、按钮贴右，符合窗口标题栏的常规布局。
- **标题栏挤压内容区**：自绘标题栏占用了原来 380 px 内容区的高度，卡片被压扁。窗口尺寸改为
  480 × 414（34 px 标题栏 + 480 × 380 内容），内容区恢复到原来的高度。
- **底部出现横向滚动条**：固定宽度窗口里内容比视口宽 14 px（竖向滚动条的宽度），会多出一条
  横向滚动条。现在内容宽度绑定视口宽度，并关闭横向滚动条。
