# v1.2.6 — 开机自动登录 + 最小化到托盘更可靠

## 🐛 修复

- **开机后程序在后台却没有托盘图标**：登录自启可能在桌面发布 StatusNotifierWatcher
  之前启动（GNOME 的 AppIndicator 扩展是异步加载的），首次创建托盘会失败，进程就变成
  一个既没有窗口也没有托盘图标的“隐形程序”，用户只能手动再启动一次。现在启动后会每
  2 秒重试创建托盘、最多尝试 60 秒；60 秒后仍没有托盘时自动显示主窗口，保证程序始终
  可以被操作。
- **保存设置后不会自动登录并最小化**：以前必须再点一次「连接」，登录成功后窗口才会
  收起。现在在界面里保存账号并勾选「自动登录」后，会立即开始登录；登录成功 3 秒后
  自动最小化到托盘（与开机自启的行为一致）。
- 之后从托盘菜单「显示主窗口」或再次启动程序，窗口都能正常唤回并完整重绘（沿用
  v1.2.4 的重绘修复）。

## 📦 其它

- 版本 1.2.6，Linux 一键安装脚本默认安装该版本；重跑安装命令即可覆盖升级。
- 无协议、配置格式或命令行参数变化。

## ⚠️ 已知限制

- Linux 版尚未经过长期真实账号保活实测；请留意在线状态。
- GNOME 需要 AppIndicator 扩展显示托盘图标；完全没有托盘的环境下程序会显示主窗口。
- 发布包按构建机 glibc 链接；较旧发行版请从源码构建。
