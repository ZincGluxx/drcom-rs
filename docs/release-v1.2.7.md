# v1.2.7 — 窗口按需创建，彻底消除 dock 里的“幽灵窗口”

## 🐛 修复

- **托盘/后台运行时 dock 里仍有幽灵窗口**：根因是程序启动时就创建了 Slint 窗口对象，
  Wayland 合成器因此在启动瞬间就登记了一个 toplevel。窗口虽然从未显示（没有缓冲区），
  GNOME Shell / Dash-to-Panel 仍把它当成“正在运行的应用窗口”列出来，点击却无法激活。
  现在**窗口按需创建**：`--silent` 启动时完全不创建窗口；第一次需要显示时（托盘
  “显示主窗口”或再次启动程序）才构建窗口并绑定回调，因此托盘后台运行时不再存在任何
  窗口对象。
- **窗口状态正确回放**：改为按需创建后，后端会记录连接状态、在线时长、最近失败信息与
  网卡详情；窗口第一次打开时把这些状态回放到界面上，不会出现“后台已登录、打开窗口却
  显示未连接”。
- 关闭窗口到托盘时窗口表面会被销毁，dock/任务栏中不再保留任何条目；再次唤回时重新
  创建并完整重绘。

## 📦 其它

- 版本 1.2.7，Linux 一键安装脚本默认安装该版本；重跑安装命令即可覆盖升级。
- 无协议、配置格式或命令行参数变化。
