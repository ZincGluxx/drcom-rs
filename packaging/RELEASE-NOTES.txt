DrCom Campus / drcom-rs — native Rust + Slint release

All platforms include drcom-campus (GUI), drcom-cli and drcom-daemon.
The daemon is not installed as a privileged/system service and is not auto-started.
LICENSE, NOTICE, THIRD-PARTY-NOTICES.md and BUILD-INFO.json travel with every package.
Source: https://github.com/ZincGluxx/drcom-rs (version/revision in BUILD-INFO.json).

Windows x64: use the installer, or extract the portable ZIP.
The installer needs administrator permission; portable programs do not.
Account/preferences data is deliberately retained on uninstall.

macOS arm64/x64: open the DMG and drag DrCom Campus.app into Applications.
The application is AD-HOC SIGNED, NOT Developer ID signed and NOT NOTARIZED.
Gatekeeper can block downloaded builds; review/trust the source before allowing it
in System Settings > Privacy & Security. Do not disable Gatekeeper globally.
CLI/daemon: '/Applications/DrCom Campus.app/Contents/MacOS/drcom-cli' --help
All three executables live together in Contents/MacOS; app resources in Resources.

Linux x64: extract tar.gz and run ./install.sh, or install .deb using apt.
The portable archive is NOT an AppImage, is dynamically linked to glibc and does
NOT bundle all system libraries. Builds use Ubuntu 22.04; newer system libraries
may be required as recorded in the .deb Depends generated by dpkg-shlibdeps.
Required GUI/tray runtime: GTK3, Ayatana AppIndicator, X11/Wayland, xkbcommon,
libxdo and D-Bus. A session Secret Service provider (GNOME Keyring or compatible)
is recommended for credential storage. No provider means secure persistence may
be unavailable: never assume plaintext fallback. GNOME needs an AppIndicator
extension for a visible tray. Optional diagnostics use curl/ping/iproute2;
NetworkManager and wl-clipboard/xclip are optional platform integrations.
Portable install is user-only (~/.local); .deb installs to /usr without enabling
a daemon/autostart. No installer removes account data.

Verify the downloaded asset with its .sha256 or the release SHA256SUMS file.
Checksums detect corruption; they are not a signature or proof of provenance.
